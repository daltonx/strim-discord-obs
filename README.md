# strim.ing Discord Activity

OBS plugin for showing your strim.ing live activity on Discord.

Download the latest build from [Releases](https://github.com/daltonx/strim-discord-obs/releases/latest).

- **Windows (x64):** extract the ZIP into your OBS plugins folder, then restart OBS.
- **macOS (Apple silicon):** unzip it, move `obs-discord-striming.plugin` to `~/Library/Application Support/obs-studio/plugins/`, then restart OBS.

In OBS, use **Tools → strim.ing Discord Activity** to connect your account and control sharing.
